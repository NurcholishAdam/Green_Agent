# Core Agent Components

This module contains the core logic for the Green Agent.

## Components

- `agent.py` - Main Green Agent orchestrator
- `base_classes.py` - Abstract base classes and interfaces
- `orchestrator.py` - Task orchestration and execution

## Integration

The core agent integrates with enhancement modules for:
- FLexGen policy optimization
- MODP multi-objective decision making
- LIMIT Graph constraint enforcement
- Bio-inspired learning
- MoE expert routing
- RLHF preference optimization
- Policy distillation
